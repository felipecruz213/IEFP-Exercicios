# 🏫 Gestão de Turma

## Detalhes da Turma
* **Número de alunos:** 8

## 💾 Estruturas de Dados Necessárias
Para armazenar as notas dos 8 alunos, serão necessários 4 *arrays*:
* Array que guarda as notas de **Matemática**
* Array que guarda as notas de **Inglês**
* Array que guarda as notas de **Português**
* Array que guarda as notas de **História**

## 📝 Requisito Inicial
* Carregar as notas das 4 disciplinas.
* As notas devem ser **validadas de 1 a 20**.

---

## 💻 Menu de Opções
O programa deve permitir as seguintes opções:

### 1. Mostrar Médias
* Mostrar a **média de todas as disciplinas** (i.e., a média da turma em cada disciplina).

### 2. Disciplina com Mais Positivas
* Indicar qual a disciplina que tem **mais notas positivas**.
    > **Nota:** Uma nota é considerada positiva se for $\ge 10$ (metade de 20).

### 3. Alunos Reprovados
* Mostrar os alunos que **reprovaram** e as respetivas notas.
    > **Critério de Reprovação:** Para reprovar é necessário ter uma nota **inferior a 8** (em qualquer disciplina) **OU** ter **média negativa** (média das 4 disciplinas inferior a 10).

### 4. Melhor(es) Aluno(s)
* Indicar qual o **melhor aluno** (ou os melhores) da turma.
    > **Critério:** O melhor aluno é aquele que tem a **maior média** (média das 4 disciplinas).

### 0. Sair
